# State backend and secret handling (static review)

## State

- Both roots start with local state (`terraform.tfstate` gitignored).
- After `ivp-tfstate` exists, `backend.s3.tf.example` is copied to `backend.tf` and
  `backend.hcl.example` to `backend.hcl` (gitignored). Migration:
  `terraform init -migrate-state -backend-config=backend.hcl`.
- `use_lockfile = true` is attempted; Hetzner Object Storage may reject it.
  The bootstrap runbook says to drop the line and stay single-operator — no
  DynamoDB table.
- `.terraform.lock.hcl` is committed (not gitignored) with windows_amd64 and
  linux_amd64 hashes so CI on ubuntu-24.04 matches the workstation.

## Secrets

| Secret | Where it lives | Why it is not in Git |
| --- | --- | --- |
| `hcloud_token`, S3 keys, Cloudflare API token | `terraform.tfvars` (gitignored) or `*.enc.tfvars` (SOPS) | `.gitignore` `**/*.tfvars` with `!**/*.example.tfvars` and `!**/*.enc.tfvars` |
| Tunnel token | Terraform state (sensitive output) and, after apply, `k8s/infrastructure/cloudflared/tunnel.secret.yaml` | File is created by the operator via SOPS in-place on the Git path; plaintext is not written under `/tmp` |
| kubeconfig / talosconfig | written next to the Hetzner root | gitignored |
| CSI LUKS passphrase | generated by the module into cluster secrets / Terraform state | state is local then S3, never Git |
| etcd snapshots | Object Storage, encrypted to `talos_backup_age_public_key` (required variable) | age public key is not secret; private key stays in `SOPS_AGE_KEY_FILE` |

`terraform.example.tfvars` holds placeholders only (`hetzner-api-token`, `cf-api-token`, `age1replacewithoutputofsopsinit`).
