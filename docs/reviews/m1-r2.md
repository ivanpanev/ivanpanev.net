## Findings

### M1-R1-F01  Medium  Reliability  Head script swallows storage errors before painting theme
Location: `apps/web/src/lib/theme.ts:62-68`; test `apps/web/tests/unit/theme.test.ts:102-116`
Problem: Round 1: a single outer `try/catch` skipped `setAttribute` when `localStorage.setItem` threw, leaving `--canvas`/`--fg` unset. The “never throws” test did not assert attributes.
Remediation direction: Set attributes first; persist in an inner try. Assert attributes in the blocked-storage test.
Status: Fixed in round 2

### M1-R2-F01  Low  Code quality  WKD unit test will fail the key ceremony
Location: `apps/web/tests/unit/wkd.test.ts:94-97`; no test covers “file git-tracked and missing” (only `IVP_REQUIRE_WKD=1` at `wkd.test.ts:100-110`); production branch `apps/web/src/integrations/wkd.ts:51-55`
Problem: `expect(await isGitTracked('src/pgp/publickey.asc')).toBe(false)` pins the pre-ceremony git state. The runbook (`docs/runbooks/pgp-key-ceremony.md:106-117`) tells the operator to commit that file; the next CI run then fails this assertion. The git-tracked-and-missing fail path that F06 added is also untested except via the env flag.
Remediation direction: Assert a path that will never be tracked (or a throwaway git repo). Drive the missing-tracked-file fail through a temp index, not through `publickey.asc`’s current untracked status.
Status: Open

### M1-R1-F02  Low  Operability  Evidence pack claims a www-redirect e2e that does not exist

Remediation direction: Drop the false claim; assert the `_redirects` rule in `check-dist`. Keep live Host confirmation on first deploy.
Status: Fixed in round 2

## Dimension notes

### Code quality — 8
Modules are still small and named for their job. Round 1’s holes in this dimension are closed: `urls.ts` has real cases, `z` comes from `astro/zod` with a clean `astro check`, the blocked-storage test asserts paint, the footer space survives compression. Coverage is 96.84% lines on the included lib/integrations surface, above the configured thresholds. What keeps this off 9 is the new ceremony-breaking `isGitTracked('src/pgp/publickey.asc') === false` assertion and the untested git-tracked-and-missing branch.

### Scalability — 9
This is still a directory of files on an edge cache. No origin compute, no N+1, no unbounded store. React ~66 KB gzip on every page because ThemeToggle is a global island (`Header.astro:37` `client:idle`); Lighthouse still scores 100, so it is a cost not a blocker. 100× traffic is Cloudflare’s problem.

### Reliability — 8
F01 no longer leaves the first paint unstyled when storage throws; F03 now matches the banner miniflare actually prints (`Ready on http://…` at INFO, which `--log-level log` maps to). Digest mismatch still fails the build; `/verify` still returns `valid: false` on tamper; e2e still targets workerd. Signing and WKD remain fail-open until the ceremony; that is documented and accepted for bootstrap. The remaining reliability risk is operational (no live `web.yml` yet), not a design hole in this milestone.

### Future-proofing and migration readiness — 8
Matches ADR-0002 (static assets, no Worker logic, no KV/D1), ADR-0003 (Astro 7, React-only islands, native view transitions, hash CSP, Fonts API), ADR-0011 (custom WikiLayout), ADR-0012 (path-filtered `web.yml`, action SHAs). TypeScript `~6.0` pin is in the ADR and the backlog. Output is a file tree; nginx/Caddy later is a copy. Deprecated `z` and the stale architecture sentence are gone. The ceremony test (F01 this round) is the leftover trap.

### Security — 8
`default-src 'none'`, hash-only `script-src`, `style-src-elem` hashed, `style-src-attr 'unsafe-inline'` only for Shiki (ADR-0003), self-hosted fonts, no runtime third parties. `getRandomValues` + rejection sampling is implemented and tested. WKD refuses private keys; Verifier refuses pasted private keys. `sign-post.sh` never hands the key to Node. Actions are SHA-pinned; preview is same-repo-only; preview message is the SHA, not the PR title; `permissions: contents: read`. Leftovers: `'wasm-unsafe-eval'` on every page (ADR-accepted for Pagefind), and `security.txt` Encryption 404s until the ceremony.

### Operability — 8
`docs/runbooks/pgp-key-ceremony.md` is still a 3 a.m. document. `apps/web/README.md` lists the commands and the “do not reuse wrangler” trap. Rollback is revert + the same artefact pipeline. The www claim is no longer a lie: `check-dist` owns the `_redirects` bytes; live Host behaviour stays operator-verify. Post-ceremony WKD absence fails the build. Missing: any live `web.yml` URL, custom-domain attach, and the ceremony itself. That is unrun CI, not a design hole.

## What was done well
- Paint-then-persist in the head script is the same split ThemeToggle already had; the blocked-storage and crypto-unavailable tests now check the attributes that CSS actually keys off, so the no-flash contract is tested on the failure path, not only the happy path.
- Deploying the verified `dist` artefact (`web.yml:188-199`) instead of rebuilding on the deploy job still removes a class of “CI was green, production was a different tree” failures.
- Third-party actions remain full-SHA pins with version comments; preview no longer interpolates `pull_request.title`.
- Secret generation is actually uniform: injectable RNG, rejection sampling, inclusion-exclusion entropy, and a chi-square test.
- signed-posts fails the build on `signed: true` without `.asc` and on digest mismatch. WKD uses the draft’s `Joe.Doe` test vector and publishes binary keys at the direct-method path; after the ceremony, a missing tracked key fails the build.
- CSP is hash-only and checked three ways. Native view transitions were chosen so `ClientRouter` would not re-execute inline scripts under that CSP.
- E2E targets `wrangler dev` rather than `astro preview`. `check-dist` now owns the www `_redirects` rule and the `security.txt` Encryption URI so those cannot drift silently.
