## Findings

### M11-R1-F01  Low  Reliability  Merge view does not write back into tabs
Location: `Editor.tsx` `MergeView` constructor
Problem: Compare mode displays two docs; edits there are not copied to `tabs` before save.
Remediation direction: On leaving compare or on cloud save, read `merge.a`/`merge.b` into the active tabs.
Status: Open — BACKLOG

### M11-R1-F02  Nit  Future-proofing  Named fonts are local() only
Location: `editor-fonts.ts`
Problem: Exocet / Chinese Rocks / etc. do nothing unless the operator has those faces installed; no files in `src/fonts/editor/`.
Remediation direction: Drop unused names or add optional woff2 as the comment already allows.
Status: Accepted (plan: bundled files optional)
